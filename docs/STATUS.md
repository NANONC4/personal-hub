### 03 What I use (`components/WhatIUse.tsx`) — ตึกหมุน 3 มิติ
- ตึกเกมเป็นกล่อง CSS 3D จริง: ด้านหน้า = ตู้เกม (`[data-cabinet]` ใน `TechBreakout`, รับ prop `sides`) · ข้าง/หลัง = ผนังมีหน้าต่างพิกเซล · หลังคา · ของบนหลังคาถอยไปกลางหลังคาด้วย translateZ
- โซนถูกตรึงกลางจอ (section สูง 200vh + sticky) · **เริ่มจากจอว่าง** → ตึกเริ่มเป็นตึกเล็กในแถวเมืองพื้นหลัง → ยกตัวออก หมุน 540° (มือถือ 180°) ขยายเข้ามา ลงจอดหันจอเกมมาหา (ตามนิ้ว 0–80% ของช่วงค้าง) → **พอลงจอดแล้ว ข้อความเล่นต่อเองตามเวลา ไม่ผูกการเลื่อน** (หัวข้อพลิกทีละตัว → คำอธิบาย → รายชื่อ → ไฟติดทีละตัวทุก 110ms รวมราว 3 วิ) · เลื่อนกลับขึ้น ข้อความจางหายไปพร้อมตึก ลงจอดใหม่ก็เล่นใหม่ · เจ้าของย้ำ: ของต้อง "มาจากที่อื่น" และคนต้องไม่งงว่าต้องเลื่อนต่อไหม
- หัวข้อ WHAT I USE พลิกขึ้นทีละตัว · รายชื่อติดไฟทีละตัว บล็อกโผล่ในเกมตาม (prop `shown`)
- กับดัก: ทุก div ระหว่างตัวที่หมุนกับหน้ากล่องต้องมี `transform-style: preserve-3d` ไม่งั้นหน้ากล่องแบนหาย · หน้าข้างต้องหันออกนอก (ซ้าย: origin-right + rotateY(-90), ขวา: origin-left + rotateY(90), หลังคา: origin-bottom + rotateX(90)) · ด้านหน้าตู้ซ่อน backface ไม่งั้นเห็นจอกลับด้านทะลุ
- ลูกบอลหลุดจอ (ทำแล้วเอาออก เจ้าของบอกไม่เวิร์กและทำเว็บกระตุก)

## กับดักที่เคยเจอ — อย่าพลาดซ้ำ

| อาการ | สาเหตุจริง / วิธีแก้ |
|---|---|
| `position: sticky` ไม่ทำงาน | `overflow-x-hidden` ที่ `<main>` ทำให้เป็น scroll container → ใช้ **`overflow-x-clip`** |
| เลเยอร์พื้นหลังหาย | `-z-10` ไปอยู่หลังพื้นหลังของ parent → ใช้ `z-0` |
| ตัวหนังสือใน canvas ผิดฟอนต์ | `ctx.font` อ่าน `var(--font-pixel)` ไม่ได้ ต้อง `getComputedStyle(...)` ก่อน · Silkscreen มีแค่ weight 400 |
| canvas เบลอบนจอ retina | ตั้ง `canvas.width` คูณ `dpr` แล้ว `ctx.setTransform` |
| framer `useScroll` ค่าไม่ขยับ | Lenis คุม scroll → ใช้ `useLenis` หรือ scroll listener + rAF |
| ตึกในเมืองจางหายเป็นหลัง | `ctx.globalAlpha` ค้างจากหน้าต่างบานก่อน → รีเซ็ตเป็น 1 ก่อนวาดตึกทุกหลัง (`PixelSky.tsx`) |
| รอยต่อหน้าต่าง → Hero กระตุก | เคยใช้ Hero ก๊อปในหน้าต่าง → แก้โดยให้มี Hero ตัวเดียว (ดู AGENTS.md) |
| หิ่งห้อยในขวดมองไม่เห็น | `<span>` เป็น inline ความกว้างเลยเป็น 0 → ใส่ `block` |
| สีอุ่นทับฟ้าน้ำเงินกลายเป็นเขียวขี้ม้า | อย่าย้อมแก้วขวดด้วยสีเหลือง ให้ตัวหิ่งห้อยเป็นแสงเอง |
| eslint `react-hooks/refs` ฟ้อง | ห้ามเขียน helper ที่คืน ref callback ใช้ `ref={(el) => { arr.current[i] = el; }}` ตรงๆ |
| `next` not recognized | `node_modules` หาย → `npm ci` |
| `npx tsc` ฟ้อง `baseUrl` deprecated | ปัญหาเดิมของ TS 6 ไม่เกี่ยวกับงาน → `npx tsc --noEmit --ignoreDeprecations 6.0` |
| eslint ทั้งโปรเจกต์มี error | error เก่าในไฟล์ที่ไม่ได้ใช้แล้ว (Lens, HorizontalScroll…) เช็กเฉพาะไฟล์ที่แก้ |

## รันยังไง

```bash
npm ci               # ครั้งแรก หรือเมื่อ node_modules หาย
npm run dev          # http://localhost:3000
npm run build        # ต้องผ่านก่อน commit
npx tsc --noEmit --ignoreDeprecations 6.0
npx eslint <ไฟล์ที่แก้>
```
