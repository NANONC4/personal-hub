# แผนอนิเมชันหน้าแรก — "One quiet night. One small light."

อัปเดต 2026-09-26 · สถานะรวมอยู่ใน [`STATUS.md`](STATUS.md)

## เส้นเรื่อง
ทั้งหน้าคือคืนเดียวกัน เลื่อนลง = ดึกขึ้น มีแสงดวงเล็ก (หิ่งห้อย) พาเรื่องไปทั้งหน้า
โทน: **สงบ pixel art lofi** เทียบกับหน้าต่างเวลคัมและ Hero ที่ทำเสร็จแล้วเสมอ

## กฎ
1. ว้าวที่ไอเดีย ไม่ใช่ความเร็ว: ท่าเล็กอย่างน้อย 0.6 วิ ฉากใหญ่ 1–2 วิ
2. แสงเล่าเรื่องด้วยการติด-ดับ ไม่มีแสงฟุ้ง ไม่มีแฟลช ไม่มีจอสั่น ไม่มีเด้ง
3. ข้อความอ่านได้โดยไม่ต้องรอนาน · ห้ามท่าแฮกเกอร์ (ถอดรหัส, พิมพ์ทีละตัว) และท่าเกมตู้ (นับถอยหลัง, ป้ายพลิก)
4. ของมีชิ้นเดียว ห้ามทำก๊อปมาสลับกับของจริง
5. สองโซนห้ามใช้ท่าเดียวกัน · ไม่มีท่าเลื่อนเข้าจากซ้ายขวา · 1 โซน = 1 จอ
6. `prefers-reduced-motion` → เห็นภาพสุดท้ายเลย

## วิธีทำแต่ละโซน
1. คุยข้อความของโซนก่อน (เจ้าของเลือกจากตัวเลือกหลายข้อ)
2. เสนอท่าเข้าเป็นสตอรี่บอร์ดที่ขยับได้ 3–5 แบบ ใช้ข้อความจริง
3. ทำจริงตามที่เลือก ทดสอบในเบราว์เซอร์ (คอม + มือถือ) แล้วให้เจ้าของลอง
4. แก้ทีละนิดตามที่เขาทัก
