## เส้นเรื่อง
ทั้งหน้าคือคืนเดียวกัน เลื่อนลง = ดึกขึ้น มีแสงดวงเล็ก (หิ่งห้อยพิกเซล) ที่คนดูตามลงไปทั้งหน้า
และกลายร่างในแต่ละโซน

## กฎ "ชิวแต่ว้าว"
1. ว้าวที่ไอเดีย ไม่ใช่ความเร็ว: ท่าเล็ก ≥ 0.6s ฉากใหญ่ 1–2s
2. ไม่มีจอสั่น ไม่มีแฟลชขาว ไม่มีเด้ง
3. แสงคือพระเอก อำพันใช้กับของที่เปล่งแสงเท่านั้น
4. ทุกท่าต้องเล่าเรื่อง
5. ไม่มีสองโซนใช้ท่าเดียวกัน ทั้งฉากและข้อความ ไม่มีท่าเลื่อนซ้าย-ขวา
6. `prefers-reduced-motion` → เห็นภาพสุดท้ายของฉากเลย
